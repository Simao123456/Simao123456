## 📂 Projetos

1. **Roulette Game**  
   - Jogo de roleta implementado com backend em Kotlin e persistência em ficheiros (simulação de base de dados).  
   - Gestão de apostas, créditos e histórico de jogos.  
   - [Repositório](https://github.com/Simao123456/Roulette-Game)

2. **Automatic Repository Generator**  
   - Ferramenta em Kotlin que gera repositórios automaticamente usando reflexão e bytecode dinâmico.  
   - [Repositório](https://github.com/Simao123456/Automatic-Repository-Generator-using-Kotlin-Reflection-Dynamic-Bytecode)

3. **CITES - Sistema de Partilha de Trotinetes**  
   - Plataforma de backend para gestão de trotinetes elétricas partilhadas.  
   - Funcionalidades: registo de utilizadores, gestão de scooters, reservas, arranque e estacionamento de trotinetes, e monitorização de estado.  
   - Base de dados PostgreSQL com persistência de utilizadores, scooters, viagens e histórico.  
   - Tecnologias usadas: Kotlin, Spring Boot, PostgreSQL, Docker.  
   - [Repositório](https://github.com/Simao123456/Scooter-Sharing-Project.git)
