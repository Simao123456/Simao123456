## Selected projects

### [PokerDice](https://github.com/Simao123456/PokerDice-Game)

Multiplayer web application with a modular Kotlin/Spring backend, React client, PostgreSQL, Docker Compose, and two backend replicas behind Nginx. The project includes server-side game state, authentication, REST/OpenAPI documentation, and explicit transaction boundaries.

### [Automatic JDBC Repository Generator](https://github.com/Simao123456/Automatic-Repository-Generator-using-Kotlin-Reflection-Dynamic-Bytecode)

Kotlin persistence experiment that maps annotated domain models through reflection and runtime bytecode generation. Includes PostgreSQL integration tests, deferred queries, and JMH benchmarks against hand-written JDBC.

### [Roulette Game](https://github.com/Simao123456/Roulette-Game)

Academic hardware/software system combining Kotlin control software with VHDL components for keypad input, displays, serial communication, roulette control, and simulation testbenches.

### [Scooter Sharing / CITES](https://github.com/Simao123456/Scooter-Sharing-Project)

Coursework repository containing the supplied Java/Maven and PostgreSQL project scaffold. The current public snapshot is incomplete and is kept for academic reference rather than presented as a finished application.
